# Домашнее задание к работе 11: Структуры данных (Вариант 6)

## Условие задачи

> Создать структуру для хранения записи «Растение». Организовать ввод трех значений структурного типа. Выполнить обработку 3 переменных структурного типа согласно варианту: вывести сведения о растениях, которые нужно поливать не реже одного раза в 5 дней и высота которых превышает заданное значение.

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**
2. **Объявление структуры `Plant`:**
   * `name[50]` — название растения.
   * `species[50]` — вид.
   * `date[20]` — дата посадки.
   * `height` (float) — высота в см.
   * `watering` (int) — частота полива в днях.
3. **Ввод данных:**
   * В цикле (3 раза) запросить у пользователя название, вид, дату, высоту и частоту полива.
   * Запросить минимальную высоту для поиска (`target_height`).
4. **Вычисления (обработка):**
   * Проверить условие: если частота полива меньше или равна 5 (`watering <= 5`) И высота больше заданной (`height > target_height`), то вывести информацию о растении и установить флаг `found = 1`.
5. **Вывод результатов:**
   * Если флаг `found` остался равен 0, вывести сообщение "Таких растений нет".
6. **Конец**

## 2. Реализация программы

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>

struct Plant {
    char name[50];
    char species[50];
    char date[20];
    float height;
    int watering;
};

int main() {
    setlocale(LC_ALL, "RUS");

    struct Plant p[3];
    float target_height;
    int i;
    int found = 0;

    printf("--- ВВОД ДАННЫХ О РАСТЕНИЯХ ---\n");
    for (i = 0; i < 3; i++) {
        printf("\nРастение %d:\n", i + 1);

        printf("Название (без пробелов): ");
        scanf("%s", p[i].name);

        printf("Вид (без пробелов): ");
        scanf("%s", p[i].species);

        printf("Дата посадки (ДД.ММ.ГГГГ): ");
        scanf("%s", p[i].date);

        printf("Высота (см): ");
        scanf("%f", &p[i].height);

        printf("Частота полива (раз в N дней): ");
        scanf("%d", &p[i].watering);
    }

    printf("\nВведите минимальную высоту для поиска: ");
    scanf("%f", &target_height);

    for (i = 0; i < 3; i++) {
        if (p[i].watering <= 5 && p[i].height > target_height) {
            printf("Название: %s\n", p[i].name);
            printf("Вид: %s\n", p[i].species);
            printf("Дата посадки: %s\n", p[i].date);
            printf("Высота: %.1f см\n", p[i].height);
            printf("Частота полива: раз в %d дн.\n", p[i].watering);
            printf("-----------------------------------\n");
            found = 1;
        }
    }

    if (found == 0) {
        printf("Таких растений нет.\n");
    }

    return 0;
}
```
